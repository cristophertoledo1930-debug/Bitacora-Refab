# Equipo Re-Fab
Bienvenidos al repositorio oficial del equipo **Re-Fab** para el curso Capstone Intermedio (Primavera 2026).

##  Sobre nuestro proyecto
Estamos trabajando en el **Desafío 05 de Sostenibilidad**, enfocado en la circularidad y manejo de residuos de fabricación digital para el **Lab881** de la Municipalidad de Providencia. 
Nuestro objetivo es diseñar e implementar una alternativa técnica para gestionar los flujos de residuos más complejos, específicamente la resina de impresión 3D y las mermas de corte láser.
