# Reparación y operación local — 2026-10-19

## Fallos observados y correcciones

- `.venv` apuntaba al Python 3.12.10 de una ubicación inexistente. Reconstruido con Python 3.12.14 disponible e instalado editable nuevamente.
- PostgreSQL terminaba con `-1073741515`. Agregadas las tres DLL Visual C++ faltantes desde el runtime local.
- Recuperación inicial bloqueada por `pgdata/server.log`: reinicio controlado con log fuera del directorio de datos.
- Conexión local estabilizada con `127.0.0.1`; copia previa de BD antes de reparaciones funcionales.
- Prefijo WSGI de Dash duplicado: rutas internas `/`, solicitudes externas `/dashboard/`.
- Dashboard carecía de protección propia. Middleware protege la ruta; modo escritorio explícito exige loopback, Host local y desarrollo.
- Correo deshabilitado se marcaba enviado. Ahora permanece pendiente. SMTP local recibe mensajes sin reenviarlos externamente.
- Entregas inciertas no se reenvían; Message-ID estable, límite de tres intentos y espera progresiva.
- Bloqueos PostgreSQL serializan creación de informe y entrega; snapshot bajo REPEATABLE READ.
- Agregaciones mensuales y tarjeta del mes respetan filtros. Eliminado el límite oculto de cien registros de la tabla local.
- Precisión excesiva de peso produce rechazo en vez de redondeo silencioso.
- Informes trasladados recuperan su ruta solamente si el SHA-256 coincide.
- PDF incorpora máquina/material y cabeceras repetidas al continuar tablas.

## Operación y límites

Las revisiones históricas no se modifican; una corrección genera otra revisión.
